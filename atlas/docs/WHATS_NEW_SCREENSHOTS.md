# What's new, in pictures (0.3.0 → 0.5.0 in progress)

Every screenshot here was taken by the automated end-to-end run of the real desktop app, on Linux, at
version 0.4.2.

**Read these with two things in mind:**
* **It is the test build.** Voice uses clearly labelled stand-in engines and tiny stand-in downloads,
  so a file size like "1 MB" or a recognised sentence like "What is 6 times 7?" is test data. The real
  sizes are in [VOICE_MODELS_AND_BENCHMARKS.md](VOICE_MODELS_AND_BENCHMARKS.md).
* **No real microphone, speaker, tray or system notification appears here.** Those have not been tried
  by a person yet.
