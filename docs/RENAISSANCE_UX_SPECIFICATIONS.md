# Prometheus 2.0: UX specifications (experience-first pass)

One identity, many experiences: every screen below has its own purpose, composition and interaction
model. Shared: tokens, icons, toasts, the activity centre, keyboard access. Screenshots in
`screenshots/renaissance/` (sample data created through the app's own code paths; labelled as such).

| Screen | Purpose · primary journey | Composition | Interaction model | Empty · loading · success · error |
|---|---|---|---|---|
| Home (01, 22) | "What's going on, what next?" → ask, or continue | Editorial: solar welcome with a real ask box and starter chips; two unequal columns: Continue + Today and next / Needs you + At a glance | Ask sends to the Companion; Continue resumes the exact conversation, task or mission; Needs you lists only real items (no provider, overdue, patches, failing tools); Customize hides sections | "All clear" in green with ✓ · loads in background · items open their source · per-part "Unavailable" |
| Companion (02, 20) | Conversation | Immersive reading column (max 880 px) with a slim presence bar (64 px sun + state in words); conversation list and context panel are toggles (remembered) | Enter sends, Shift+Enter new line, / commands, Esc stops; on replies: Copy, Regenerate, **Use as task steps** (lists only); starters in an empty conversation fill the box | Welcome with starters · streaming at ≤ 20 renders/s · tool lines with outcome words · error line with Retry |
| Memory (03, 23) | "What does Prometheus know, is it right?" | Library: category rail with counts + Review queue · readable rows · inspector | Select → inspector (provenance, dates, importance now, links, earlier versions) → Confirm / Correct / Forget; Add a memory warns on duplicates and conflicts | Review: "✓ Nothing to review" · background load · toast on every change · toast with the reason on failure |
| Engineering (04) | Numbers, and understanding a project | Workbench: mode switch; studio = library · form · result sheet led by the headline value; project intelligence = repository, make-up, entry points, tests, code search | Enter calculates; "Ask Prometheus to check this"; code search results open in Workspace; "Review it" pre-fills an Architect mission | Sheet invites input · toast on calculation error · "No test files found (looked for …)" |
| Forge (05, 17) | Start and follow project work | Mission studio: missions rail · guided start (1 project, 2 objective, 3 discipline suggested from the wording, 4 scope) · mission workspace | Stages light up only from recorded tool calls; files, runs, refusals and the report use the discipline's own words (Plan and findings / What was built / Root cause and fix / Recovered architecture) | "No report yet: running, waiting for approval or stopped" · toast "mission started" (acknowledged, not done) |
| Workspace (06, 21) | Find and read files | Explorer: project switcher + tree · overview or preview · inspector | No selection = workspace overview (projects, recent changes), never a blank panel; inspector actions: open with the system, copy path, ask Prometheus, show in folder; read-only Git | Overview explains how to add a project · refused previews say why (.env, binary, outside) |
| Reminders & tasks (07) | Keep commitments | Planner: views rail with counts (Today, Upcoming, Overdue, Repeating, Delivered, Cancelled) · quick-add line · day-grouped agenda · current-task checklist | Enter in "Remind me to…" jumps to "in 2h", Enter adds; Cancel per row; ticking a step writes the step list through update_task_state | View-specific empty sentences · toasts with the resolved time |
| Obsidian (08) | Read connected knowledge | Intro when no vault; reader: notes + search · Markdown · Links to / Linked from | Click a link or backlink to follow it; export goes through the Companion's approval card | Intro explains what connecting does · "No notes link here" · "(no such note yet)" for dangling links |
| Robot arm (09) | Explore reach safely | Lab studio: joints rail · large viewport · telemetry | Sliders (arrow keys, Page Up/Down), −/+ nudges, Home pose, Reach target via arm_plan; telemetry updates immediately | SIMULATION ONLY pill and sentence always visible · limit/collision warning with ⚠ and words |
| Reflection (10) | "Is Prometheus reliable?" | Insights: written headline · what to improve · reliability chart (shares, n, "few" under 5) with recent-outcome strips · usage bars · evaluations in words | Read top to bottom; chart has an accessible description | "No tool has run yet…" · suggestions only from enough calls |
| Trust & safety (11) | Oversight | Posture statement · segmented views: Timeline (by day, inspector) · Where data goes · Permissions (three groups) · Undo | Filter by kind or tool; select an event to see redacted arguments; Verify the chain → toast | "No activity yet" · broken chain shown in red words |
| Settings (12) | Change one thing | Category rail (Models & providers, Workspace, Desktop, Appearance, Privacy & autonomy, Voice, Data & backups, About) with focused pages | Changes save immediately and confirm with a toast; connection test with model choice | Secure-store warning in words · test failures name the reason |
| Activity centre (18) | "What happened?" | Drawer from the bell | Session notifications then recent audit events; selecting one opens its source | "Nothing yet…" |
| Toasts (19) | Know the result | Bottom-right stack, icon + word + text + detail | Tone words: Done / Working / Attention / Problem; also announced through the window's accessible description; dismiss by click | — |
